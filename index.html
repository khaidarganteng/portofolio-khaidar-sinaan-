Tentang Saya

Saya Khaidar Sinaan As Shidqii, berdomisili di Wonosobo. Fokus utama saya adalah video editing — mengolah footage menjadi konten dengan ritme, transisi, dan efek visual yang rapi, menggunakan CapCut dan Alight Motion sebagai tools utama.

Di luar editing, saya juga memiliki kemampuan dasar web development untuk membangun halaman sederhana seperti portofolio ini.

Terbuka untuk kolaborasi project editing video, baik untuk konten media sosial, promosi, maupun kebutuhan personal.
